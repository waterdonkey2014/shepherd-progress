# Shepherd Progress

The kit-by-kit progress page of Shepherd's first port: **Cult of the Lamb** on the PS Vita (one PCH-2000).

Every kit, done and planned, each trick with a plain explanation and its effect. Kits that ran are measured on the
hardware; everything else is an estimate and says so. Known issues and the "built, not in use" shelf have their own tabs.

- The page: https://waterdonkey2014.github.io/shepherd-progress/ (`index.html`, one standalone file)
- The engine (for any Unity game): https://github.com/waterdonkey2014/shepherd
- The companion Claude plugin (the tricks, gotchas and ideas): https://github.com/waterdonkey2014/shepherd-vita-plugin
